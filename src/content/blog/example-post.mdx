## Use "##" for section headings

Each `##` heading starts a new section. Use `###` for sub-points inside a section. Don't
use a single `#`: the post title is already the page's main heading.

### A sub-heading

Normal paragraphs are just lines of text. Leave an empty line between paragraphs. You can
write **bold text**, _italic text_ and [links to other pages](/#services). Links to other
websites, like [Upwork](https://www.upwork.com), open in a new tab automatically.

## Images

Put image files in `public/images/blog/` and use the `Figure` block, with the image's real
width and height, so the page doesn't jump while it loads:

next step for the reader, for example inviting them to get in touch.

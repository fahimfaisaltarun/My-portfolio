# Fahim Faisal Tarun — Portfolio

Premium, dark, motion-heavy portfolio for a freelance video editor & motion designer.

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · GSAP 3 · Lenis

## Getting started

```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_SITE_URL
npm run dev                  # http://localhost:3000
```

Design tokens preview: http://localhost:3000/design

## Scripts

| Command         | Does                     |
| --------------- | ------------------------ |
| `npm run dev`   | Dev server (Turbopack)   |
| `npm run build` | Production build         |
| `npm run start` | Serve production build   |
| `npm run lint`  | ESLint                   |
